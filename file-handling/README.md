# File Handling 📁

A beginner-friendly command-line application that demonstrates basic file handling operations in Python.

## Features

- Create a data folder automatically
- Add multiple tasks
- Store tasks in a text file
- View saved tasks
- Input validation
- Exception handling

## Concepts Practiced

- File Handling
- Functions
- Loops
- Exception Handling
- `os` Module
- User Input Validation

## Folder Structure

```
file-handling/
│
├── data/
│   └── tasks.txt
│
├── files.py
└── README.md
```

## Run

```bash
python files.py
```
