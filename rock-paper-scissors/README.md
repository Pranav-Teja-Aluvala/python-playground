# Rock Paper Scissors

A command-line game against a random computer choice.

From the repository root:

```bash
python rock-paper-scissors/rock_paper.py
```

Enter `rock`, `paper` or `scissor` (singular, as used in the code). A win ends the game; losses and ties prompt another round. Those restarts currently use recursion, so long sessions should eventually be changed to a loop. Press Ctrl+C to stop.
